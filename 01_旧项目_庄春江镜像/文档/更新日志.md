### 2026-11-10 下午：全站简繁切换完成

**产出目录**：`agama.buddhason.org_simp/`（原站镜像 `agama.buddhason.org/` 保持不变）

**三类页面处理方式**：
1. **新版三段式**（含 `agama/nikaya/comp`）—— 6682 页，各段分别生成 `.trad`/`.simp` 两份；
2. **無對讀經文**（只有北傳、無南傳/巴利，共 624 页：SA 364 / AA 237 / MA 20 / DA 3）—— 只把經文正文包成 `.trad`/`.simp`（用 div 包裹，避免 span 不配对）；
3. **栏目 index / book / study / 根目录** —— 269 页，整 body 包 trad/simp。

**统一开关**：右下角小按钮（11pt、半透明），放在 `#north` 内（不破坏 ExtJS 布局）；全部共享 `localStorage('agama_lang')`，一处切换全站生效。

**踩过的坑（已解决）**：
- 浮动条放在 body 顶层会让 ExtJS Viewport 初始化异常 → 改放 `#north` 内；
- 旧格式整 body 包装会重复 `draw_layout()` → 只包正文；
- 無對讀頁用 `<span>` 包裹会因原标签不配对导致 simp 被嵌套 → 改用 `<div>`；
- 恢复脚本在 `<head>` 执行时 `document.body` 为 null → 加 `DOMContentLoaded` 保护。

### 2026-11-11 凌晨：全站前端化（不再需要本地服务器）

**背景**：站点已不再更新，把三类动态功能全部改为纯前端，`file://` 双击即可使用。

**1. 经文比对**
- `map.js`（79.7 KB）：SN/AN 经号映射；
- `dm.html` / `sn.html` / `an.html`：纯 JS 查表跳转；
- 3964 页 `action` 路径修正（`../`）。

**2. 注释**
- `note/note0.js`~`note9.js`（繁体）+ `note0_s.js`~`note9_s.js`（简体），共 999 条；
- `show_note` 从 `$.load`（AJAX，被 CORS 拦）改为**动态插入 `<script>`**（不受限制）；
- 30 个栏目 JS 已同步修改。

**3. 全文搜索**
- 每栏目一个 `search_XX.js`（繁体 `x` + 简体 `xs` 双字段），共 6579 页 / 67.94 MB；
- 每栏目一个 `XXsearch.html`（客户端 `indexOf` 匹配 + 片段高亮）；
- 7323 页搜索表单从 `XXsearch.php` 改为 `XXsearch.html`，并修正 `../` 路径。

**关键坑**：
- `$.load` / `$.getScript` 都走 XHR，`file://` 下被 CORS 拦截 → 必须用 `<script src>` 或 `document.createElement('script')`；
- 子目录页面的 `action` 必须加 `../`；
- 索引要同时含繁简两版，否则切换语言后搜不到。

**备份**：`_backup/20261111_前端化前/`（8267 文件 / 220.8 MB）
