## 一、目标

把庄春江工作站（agama.buddhason.org，已停更）从「镜像站」重构为**独立的离线阅读软件**：

1. 体积尽可能小（原镜像 289.8 MB → 主包 14.1 MB）；
2. Windows 与 Android 都能装、能离线用；
3. 不联网、不申请权限、不读外部数据；
4. 保留原站内容与功能：经文、巴利原文、注释、全文搜索、繁简切换。

## 四、技术方案

### 4.1 数据层

- `corpus/*.json.gz`：按系列拆分的经文集（去重后的正文、比对、巴利引用）；
- `pages.json.gz`：7306 个页面的组成（keys / 覆盖 / 比对 / 巴利 id / 栏目 / 经号）；
- `pali.json.gz`：巴利原文，按内容哈希去重（15.6 MB → 3.4 MB）；
- `toc.json.gz`：首页、24 个栏目页、著作目录与正文、参考页的原始 HTML（链接已改写）；
- 合计 11.4 MB（gzip）。

### 4.2 前端

- 原生 JS 单页，hash 路由；
- `DecompressionStream('gzip')` 解压数据；
- 静态页（原站 HTML）直接渲染，链接改写为内部路由，图片放 `assets/`；
- 经文页：两栏布局（北传页两栏同文、各自滚动；南传页左汉译右巴利）；
- 搜索：内存扫描，按栏目过滤，简体关键词转繁体再匹配；
- 未实装入口统一跳 `#/notice`。

### 4.3 Windows 壳

- C# WinForms + WebView2，用系统自带 `csc.exe`（.NET Framework 4.8）编译，无需 SDK；
- AnyCPU：`loader\x64`、`loader\x86` 各一份 WebView2Loader，按位数 `SetDllDirectory`；
- `SetVirtualHostNameToFolderMapping("app.local", "ui")`，避免 file:// 限制；
- DPI：`app.manifest` + `exe.config`（PerMonitorV2）；
- 便携：`userdata` 放程序旁，不可写时退回 `%LOCALAPPDATA%`；
- 单实例、关键文件检查、启动阶段日志（`startup.log`）。

### 4.4 Android 壳

- 纯框架 Java（不引 AndroidX），`shouldInterceptRequest` 把
  `https://appassets.androidplatform.net/` 映射到 APK 的 `assets/`；
- Gradle 8.9 + AGP 8.7.3，compileSdk 35 / minSdk 24 / targetSdk 35，包名
  `io.github.yoshikichi99.zcjreader`；
- 数据文件打包时从 `*.json.gz` 改名 `*.gz.bin`：AGP 的 `AssetItem.shouldBeUnGzipped()`
  会按 `.gz` 后缀自动解压 assets（不改名 APK 会多 2.4 MB）；
- 返回键 → `history.back()`；Android 15+ 强制 edge-to-edge，用 `FrameLayout` +
  `MarginLayoutParams` 给 WebView 设真实外边距（**WebView 的 padding 不缩进网页视口**）；
- 手机端前端分叉：`app.js` 在 ≤760px 时**一律单栏**，顺序固定
  漢譯 → 南北傳經文比對 → 巴利語；栏目页头图按「有墨的列」切分（标题 75% 宽 + 回首页）；
- 不申请任何权限；APK 12.96 MB，冷启动实测 474 ms、PSS 233 MB。

## 五、目录与构建

```
工具\
  extract.py          从镜像抽取页面
  build_model.py      页面视图模型
  build_final.py      生成 corpus/pali/pages/books/docs
  build_toc.py        生成 toc（原站静态页拷贝、未实装入口重定向）
  build_audio.py      生成音频扩展包（按标题命名）
  build_pdf.py        生成 PDF 扩展包（按书名命名）
  t2s.js              繁转简（浏览器/Node 共用）

前端\proto\           开发版界面（可直接起 HTTP 服务预览）
构建\Windows\src\     Program.cs、app.manifest、exe.config
构建\Windows\dist\    成品：莊春江讀經站\、音频扩展包\、PDF扩展包\
```

重新构建：

1. `python 工具\build_final.py`
2. `python 工具\build_toc.py`
3. `python 工具\build_nummap.py`、`python 工具\build_menus.py`
4. `python 工具\build_audio.py`、`python 工具\build_pdf.py`（两个扩展包）
5. `构建\Windows\打包.cmd`（同步 `前端\proto` → `dist\莊春江讀經站\ui`，并写 `授權說明.txt`）
6. 单文件包：`python 工具\build_zip.py`，再按更新日志第 48 节的 `csc` 命令编译

## 六、Android 实现要点（已落地，2026-11-12）

1. **前端零改动**：`前端\proto\` 原样进 `assets/`，入口 `index.html`；
2. **加载方式**：自实现 `WebViewClient.shouldInterceptRequest` 映射
   `https://appassets.androidplatform.net/`，保持 https 环境（`fetch`、`localStorage` 正常），
   不引 AndroidX，比 `WebViewAssetLoader` 少一个依赖；
3. **能力依赖**：`DecompressionStream` 实测可用；未内置 pako 兜底，
   遇到极旧 WebView 会提示「此瀏覽器不支援」——列入已知限制；
4. **体积**：APK **12.96 MB**（数据 11.6 MB gz + assets 1.3 MB）；
5. **返回键**：映射到 `window.history.back()`；
6. **字体**：Android 自带 Noto Sans CJK，未内置；
7. **音频/PDF**：仍作为独立扩展包，不打进 APK（与 Windows 一致）；
8. **安全区**：Android 15+ 强制 edge-to-edge，用容器外边距缩进 WebView；
9. **最低版本**：minSdk 24 / targetSdk 35，compileSdk 35。

## 七、待办

## 八、已知限制

- 部分页面注释与原站有细微差异（719 页），以原站为准保留；
- 栏目页的「大正本/正聞本/佛光本」与「經號」输入框**已实装直接跳转**（映射见 `data/num.json.gz`）；
  输入未收录的号时会提示「找不到經號」，不再退化成全文搜索；
- 音频未压缩，扩展包 80.7 MB；
- 打印/导出、缩放、自动更新不做。
