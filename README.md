# 莊春江讀經站 · 離線閱讀器

把已停更的 [agama.buddhason.org](http://agama.buddhason.org)（莊春江工作站）从「网页镜像」重构为**独立的离线阅读软件**：不联网、不申请权限、不读外部数据，体积从原镜像 289.8 MB 压到主包 14.1 MB。

## 仓库内容

| 目录 | 内容 |
|---|---|
| `01_旧项目_庄春江镜像/站点_纯净版/` | 原站完整镜像（繁体，8003 文件 / 170 MB），作为内容源与最终校验对照 |
| `02_新项目_离线阅读器/` | 当前离线阅读器的工作区：抽取脚本、前端、Windows 壳、构建脚本、文档与校验报告 |
| `目录说明.md` | 工作区目录与各阶段产物的说明 |

`01_旧项目_庄春江镜像/` 下的备份、分发包、过程文件、脚本工具、简体版镜像体积过大或属过程产物，不纳入本仓库；`02_新项目_离线阅读器/源数据/`（290 MB 工作副本）与构建产物同样不入库，见 `.gitignore`。

## 离线阅读器做了什么

- **数据层**：从镜像抽取正文、比对、巴利原文、注释，去重后压成 gzip 包（11.4 MB）；
- **前端**：原生 JS 单页，hash 路由，`DecompressionStream('gzip')` 运行时解压；首页/栏目/著作页直接沿用原站 HTML，只有经文阅读页重写；
- **Windows 壳**：C# WinForms + WebView2，用系统自带 `csc.exe` 编译，无需 SDK；单实例、便携 `userdata`、启动自检；
- **功能**：全文搜索（限本栏目）、繁简运行时切换（逐页校验 99.85% 一致）、注释、双栏对照；
- **扩展包**：音频（80.7 MB / 48 段）与 PDF（6.6 MB / 7 本）各自独立成包，不内置。

## 重新构建

```bat
cd 02_新项目_离线阅读器
python 工具\build_final.py
python 工具\build_toc.py
python 工具\build_audio.py
python 工具\build_pdf.py
```

Windows 壳编译与打包步骤见 `02_新项目_离线阅读器/文档/项目总览.md` 第五节，以及 `文档/更新日志.md` 第 32、36 节。

> 构建的输入是 `02_新项目_离线阅读器/源数据/`（镜像工作副本，未入库），需先从 `01_旧项目_庄春江镜像/站点_简体版/` 复制。
